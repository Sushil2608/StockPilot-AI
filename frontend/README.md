# StockPilot AI frontend

The frontend is built with Next.js. For prerequisites, setup, environment
variables, Docker, and Vercel deployment, see the [project README](../README.md).

To run the frontend locally, install dependencies with `npm ci` and start the
development server with `npm run dev`. Set `NEXT_PUBLIC_API_URL` to the backend
origin when it is not running at `http://localhost:8000`.
